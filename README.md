# MAUI Daily Assistant

A multi-purpose mobile application developed with C# and .NET MAUI that brings useful daily information and personal planning tools together in a single application.

## Features

- 🌤️ Weather information
- 💱 Currency exchange rates
- 📰 News bulletin
- 📅 Personal reminders and plans
- 🔔 Reminder notifications
- 📱 Simple and user-friendly mobile interface

## Technologies

- C#
- .NET MAUI
- XAML
- .NET
- Visual Studio

## Application Modules

### Weather

Provides current weather information to help users follow daily weather conditions.

### Currency

Displays currency exchange information for commonly used currencies.

### News

Provides a news bulletin where users can follow current news and updates.

### Planner & Reminders

Allows users to create plans and reminders so they can keep track of important tasks and events.

Learning Objectives

This project was developed to gain practical experience with:

.NET MAUI
C# programming
XAML UI development
API-based data usage
Mobile application development
Event handling
Notifications and reminders
Working with multiple application modules
Purpose

The goal of the project is to combine frequently used daily tools into one cross-platform mobile application.
